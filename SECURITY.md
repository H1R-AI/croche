# Security

Report a vulnerability **privately**, never in an issue.

- During the closed beta: write to the Croche team through the channel your beta invitation
  came from, with "SECURITY" in the subject.
- From the public beta: GitHub's private vulnerability reporting on this repository.

Include what you found, how to reproduce it, and what it lets an attacker do.
